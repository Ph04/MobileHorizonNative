MobileHorizonNative - Android LWJGL native dependency
======================================================

The bundled liblwjgl.so is built at CI time for Android arm64-v8a, API 26.
It contains LWJGL 3.4.1 core native code and statically linked libffi 3.5.0.
No OpenGL/OpenGL ES rendering backend is used by this port; Horizon continues
to render through its WGPU/Vulkan renderer.
